# Product requirements and implementation traceability

The governing execution baseline remains the authority. This register preserves all 73 named launch, enterprise, ecosystem, business, resilience, handoff, headroom, feedback, comparison and research rows from Full Product Roadmap. It also retains the complete worksheet snapshot so surrounding customer questions and context are not lost.

Run `python3 check_requirements.py` for definition coverage. `--release` always refuses: a structural coverage check cannot verify independent evidence or authorize release. Owners must separately bind every required obligation to implementation, tests, exact candidate and independently verified evidence. This is a new local check, not an installed CI or branch-protection claim. Numerical enterprise targets are proposed internal acceptance targets, not achieved service levels.

## Required owner mapping

Each owner must record actual route/command → handler → service/store → trust boundary → tests for its obligations. Record unsupported interfaces, unavailable provider configuration, and unresolved choices explicitly. Shared requirements have one effort block, several accountable consumers, and one joined acceptance exit. Do not duplicate hours across repositories.

The shared object must retain organization/workspace/task, requirement version, source/candidate, dependency/checker/environment basis, actor/authority, action/destination, idempotency identity, observed outcome and resource account. Historical receipt verification, current evidence rechecking, and effect execution are distinct operations. Missing evidence never becomes a clean result or permission.

User journeys include first connection, finding, agent repair, checks, review/adoption, receipt, teammate handoff, later change, conflict, interruption, access revocation, account recovery, billing lifecycle, customer bug intake and approved release feedback. Each needs happy, missing/unsupported, denied, stale, interrupted and recovery states where applicable. The canonical Platform design contract supplies page/component/motion requirements; this register does not replace it.
